Submit a concept

What makes a concept

One idea is one entry. If you made five videos exploring the same combat scenario, that's a single concept with five explorations inside it — not five posts. Give the idea a name, say what you're proposing, and attach whatever you have.

The form asks for:

  • Title — name the idea, not the file.
  • Category — worlds, UI, gameplay, weapons, armor, abilities, subclasses, enemies, social, misc. Pick up to three.
  • The idea — two to four sentences on what you're proposing and why.
  • Key takeaways — the specific claims the concept is making. Optional, but this is what makes it read as design rather than decoration.
  • Explorations — every attempt you made, including the ones that didn't work. Say what each one was testing.
  • What to keep, what to drop — per exploration. This is the most useful thing you can write.
  • Tools and process — optional. Share as much or as little as you want.

Keep the failures

Especially for AI work, no single generation is ever quite right. Don't throw away the four that missed — annotate them.

Exploration 01 — HUD transition
  keep   HUD collapse, energy pulse
  drop   the Super itself

Exploration 03 — Weapon morph
  keep   weapon dissolve
  drop   camera shake

Exploration 04 — Environment
  keep   ground lighting response

Then pull the seconds that actually worked into Selected moments — a two-second HUD animation from one, a three-second weapon transformation from another, a single frame from a third. Together they communicate the design even though no single attempt nailed it. That's how a real concept board works.

Media

Drag images and video straight into the submission form. GitHub uploads and hosts them for you.

WhatLimit
Images and GIFs10 MB
Video — MP4, MOV, WEBM10 MB on Free plans, 100 MB on paid
Anything largerGoes on a GitHub Release — up to 2 GB per file

Video files are never committed to the repository. Say so in your submission if something is too big and it'll be uploaded to a Release for you.

If you use Git

Add a folder. One concept per folder, so submissions never conflict with each other:

concepts/your-concept-slug/
  concept.json      the entry
  notes.md          optional long-form writeup

Then check it before you push:

node .github/scripts/validate.mjs

The same check runs on your pull request. Full field reference in CONTRIBUTING.md.

See the open briefs — nobody has claimed them.

Two things that don't belong

Work you don't have the right to share, and anything presented as real or leaked Destiny 3 material. This project is fiction, openly. Read the code of conduct before posting.
